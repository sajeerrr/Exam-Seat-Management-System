# Exam Seat Management System

## Description

The Exam Seat Management System is a Python-based application that automates the allocation of students to examination halls while following predefined seating constraints. It minimizes manual effort and generates organized seating arrangements efficiently.

## Features

- Automatic exam seat allocation
- Optimized classroom utilization
- Prevents adjacent seating of the same department whenever possible
- Supports multiple classrooms with different capacities
- Efficient handling of remaining students
- Easy to customize allocation rules
- Fast and reliable seat distribution
